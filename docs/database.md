# 数据库说明

| 表 | 业务含义 | 主要关系 |
| --- | --- | --- |
| `mes_work_center` | 车间工作中心与计划产能 | 被工单、设备引用 |
| `mes_user` | 登录账号、岗位角色和所属中心 | 操作工可绑定工作中心编码 |
| `mes_work_order` | 产品、批次、计划/完工/不良数量 | 关联工作中心 |
| `mes_operation_report` | 工序、合格数、不良数、人员和时间 | 关联生产工单 |
| `mes_inspection` | 首检、巡检、完工检验 | 关联生产工单 |
| `mes_equipment` | 设备运行状态、OEE 与心跳 | 关联工作中心 |

所有表包含 `created_at` 和 `updated_at`。生产部署建议根据工厂规模对报工、采集和追溯表实施分区或归档，并对工单号、批次号、设备编码和采集时间建立组合索引。
